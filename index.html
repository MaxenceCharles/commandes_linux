🐧 Aide-mémoire Commandes Linux

📁 1. Navigation et Gestion des Fichiers

Commande Utilité Options Principales Exemples
ls Lister le contenu d'un répertoire -a (masqués), -l (détails), -h (tailles lisibles) ls -la /var/log
cd Changer de répertoire ~ (home), - (précédent) cd /var/www/html
mkdir Créer un nouveau répertoire -p (créer arborescence parente) mkdir -p projet/src/js
cp Copier des fichiers ou dossiers -r (récursif), -v (détaillé) cp -r src/ dist/

📄 2. Lecture et Édition de Fichiers

Commande Utilité Options Principales Exemples
grep Rechercher du texte dans un fichier -r (récursif), -i (insensible casse), -n (lignes) grep -rn "error" /var/log/
tail Afficher la fin d'un fichier -f (suivre en direct), -n (nb lignes) tail -f -n 50 /var/log/syslog
